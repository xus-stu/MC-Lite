# Windows（VMware）测试清单

## 环境准备

1. **Java**：启动器本体需要 **Java 21+**（推荐 25）。VM 里装好 JDK 并确保 `java -version` 可用；
   游戏 Java 由启动器自动检测/下载，不需要 VAT 里手动装 25。
2. 网络：国内建议下载 **region 版 JAR**（`MCLite_v1.4.60-region.jar`），走镜像；普通版走 GitHub/镜像竞速。
3. VMware：开启 3D 加速（显示器设置里勾选 Accelerate 3D）；否则 Java2D 可能退化为软件渲染，动画会掉帧。
4. 分辨率缩放：Windows 缩放 125%/150% 下检查字体与按钮裁切。

## 必测项

| 项目 | 预期 |
|---|---|
| 启动 | `java -jar MCLite_v1.4.60.jar` 或 `run.bat` 正常打开窗口 |
| 目录选择 | 设置 → 存储位置 → 修改游戏目录/账户目录：弹 **JFileChooser**（Windows 文件选择框），能选文件夹 |
| 窗口控制 | 最小化/最大化/还原正常；窗口尺寸 320–3840 可调 |
| 透明标题栏/红绿灯 | 不应出现（macOS 专用逻辑已用 isMac 保护） |
| 指针柔光 | 卡片 hover 有跟随渐变；设置里「全局界面柔光」默认关（实验项，开着可能闪烁） |
| 下载中心 | 版本列表加载、搜索、下载、任务进度、取消 |
| 模组/资源包 | 搜索、安装、已安装列表、删除 |
| 插件 | 下载中心 → 启动器插件：音乐播放器/地形查询/修改工具/存档备份 可安装、可打开 |
| 音频 | 音乐播放器能播放（需 ffmpeg？插件自带解码管道；VM 无声卡时看错误提示是否友好） |
| 存档备份 | 备份/恢复/删除；备份目录 `%USERPROFILE%\.mclite\backups` |
| 日志/路径 | 打开日志目录、数据目录正常（资源管理器） |
| 中文 | 全界面中文；DH 汉化资源包不涉及启动器 |
| 退出 | 关窗无残留 java 进程 |

## 已知平台差异

- **目录选择**：Windows 用 Swing `JFileChooser`（版本 1.4.60 起）；macOS 用原生对话框。
- **窗口透明度**：仅 macOS 生效（设置项在 Windows 上无效果，属预期）。
- **标题栏透明/红绿灯**：仅 macOS。
- **Metal 渲染选项**：仅 macOS。
- 启动器 JAR 上限 1.3MB，与平台无关。

## 出问题时收集

1. `%USERPROFILE%\.mclite\logs\launcher.log` 最后 100 行
2. 截图（窗口整体 + 报错弹窗）
3. `java -version` 输出、VMware 3D 加速是否开启
